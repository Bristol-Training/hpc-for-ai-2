# HPC for AI – Part 2

## Introduction

Welcome to **HPC for AI – Part 2**!

In this course, you’ll use [Isambard-AI](https://www.isambard.ac.uk/), one of the UK's national supercomputers for AI research, to run a Large Language Model (LLM) and fine-tune it for a specific purpose.

The course is organised into two main steps:

1. **Run an LLM** – Load and run an open-weights Large Language Model on Isambard-AI and explore how it responds to different prompts.
2. **Fine-tune an LLM** – Adapt the model for a specific task and evaluate whether fine-tuning has improved its performance.

## Intended Learning Outcomes

By the end of this course, you will be able to:

- Understand the memory and computational requirements of LLMs, including approximately how much memory a model of a given size requires.
- Load an open-weights LLM onto an Isambard-AI GPU and generate text using the model.
- Understand how prompt settings, such as temperature and maximum generation length, influence the model's output.
- Prepare a dataset in the appropriate format for fine-tuning.
- Fine-tune an LLM for a specific task using a single GPU.
- Work considerately on a shared supercomputer, including best practices for storing and managing large model files.

## Getting Started

Work through the course materials in order, following the instructions provided in each section.

You'll gain practical experience of running and adapting LLMs on a national-scale GPU supercomputer.
